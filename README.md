**Overview**
This repository contains the source code for my personal portfolio website. It serves as a showcase of my skills, projects, and professional background as a fullstack web developer. The portfolio is designed to be responsive, performant, and user-friendly, providing visitors with a clear view of my technical expertise and creative work.

**Features**
Responsive design optimized for desktop, tablet, and mobile devices

Project showcase with detailed descriptions and live demos

Contact form integrated with backend services for secure submissions

Dynamic content powered by modern frameworks

SEO optimization for improved visibility

**Tech Stack**
Frontend: HTML5, CSS3, JavaScript (ES6+), React

Backend: Node.js, Express

Database: MongoDB

Version Control: Git, GitHub

Deployment: Vercel / Netlify / Heroku
